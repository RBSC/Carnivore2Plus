There are 2 main flavors of the boot menu:

\NoGfxTit\BOOTCMFC.BIN		- folder for Boot Menu with text-only title screen
\NoGfxTit\Special\BOOTCMFC.BIN	- folder for custom Boot Menu with text-only title screen for Korean and Arabic MSX computers;
				  it can be also used with any other MSX
