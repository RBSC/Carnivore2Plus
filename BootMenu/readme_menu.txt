The Boot Menu code and the custom font were created by RBSC.

There are 2 main flavors of the boot menu:

\BOOTCMFC.BIN		- standard Boot Menu, suitable for most of MSX computers
\Special\BOOTCMFC.BIN	- folder for custom Boot Menu for Korean and Arabic MSX computers; it can be also used with any other MSX
\NoGfxTit\BOOTCMFC.BIN	- standard Boot Menu without graphics title, suitable for most of MSX computers
\NoGfxTit\Special\BOOTCMFC.BIN	- folder for custom Boot Menu without graphics title for Korean and Arabic MSX computers; it can be also used with any other MSX

See the readme.txt file for more info.
